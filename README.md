# 私域话术库快捷回复

> 篝火出品 · 收录于篝火 App 应用区

桌面小窗，按场景搜话术一键复制

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/script-quick-reply/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `script-quick-reply_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `script-quick-reply_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `script-quick-reply_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

1. **打开就能搜**：光标已经在搜索框里，输入关键词（如「嫌贵」）或拼音首字母（如 `cd` = 催单、`jgyy` = 价格异议），多个词用空格隔开。
2. **回车复制第一条**：第一张卡片带蓝框；按 ↑ ↓ 换选中的那条，回车复制。也可以点卡片上的文字或「复制」按钮。复制后到微信里直接粘贴。
3. **变量**：话术里用大括号写要每次替换的地方，比如 `{客户称呼}`、`{快递单号}`。复制前会弹出填写框，填完回车就复制好了；上次填过的值（如「我的名字」「店铺名」）会自动带出，没填的变量保留原样，方便你发出前发现。
4. **分类**：左侧是分类树，用「/」可以建二级分类（如「售后/物流」）；鼠标移到分类上可以重命名或删除（只能删空分类）。「置顶」里是所有置顶话术。
5. **新增 / 编辑 / 删除 / 置顶**：右上角「新增」（快捷键 ⌘/Ctrl + N），卡片底部的图标可以置顶、编辑、删除。置顶的话术永远排在最前面，其次按搜索匹配度和复制次数排序。
6. **示例话术**：第一次打开会放入 24 条示例（16 条销售话术 + 8 条群欢迎语 / 群公告模板，都标有「示例，可删除」），可以直接改成自己的，或点顶部「删除全部示例」一次删掉。
7. **导入**：点「导入」或直接把文件拖进窗口，支持 `.xlsx`、`.csv`、`.json`。表格第一行是表头，识别「分类 / 标题 / 话术内容 / 置顶」（也认「场景」「话术」「内容」等写法，列顺序不限）；同一分类下内容相同的话术会自动跳过，不会重复。
8. **群欢迎语 / 群公告模板（0.2.0 新增）**：左侧「群欢迎语与公告」分类下有入群欢迎、群规公告、活动通知、开课提醒共 8 条示例模板，文案是通用示例，请按自己的群改写。变量写法同上，如 `{群名}`、`{成员昵称}`、`{活动名}`、`{活动时间}`、`{开课时间}`；点复制会弹出填写框，填完回车，剪贴板里就是替换好的标准文本（统一换行、去掉行尾空格、连续空行合并为一行；没填的变量保留 `{…}` 原样以便发现）。新增 / 编辑话术时可点「插入变量」里的 `{群名}`、`{活动时间}` 等。从 0.1.0 升级的话术库会自动补入这 8 条（只补一次，删掉后不会再出现，原有话术不受影响）。
9. **导出**：「导出 → 导出 Excel」方便发给同事；「导出 JSON 备份」是完整备份（含空分类），换电脑时导入即可恢复。

**数据存在哪**：话术库只保存在本机的 `settings.json`（键名 `library.w12`），不联网、不上传：
- Mac：`~/Library/Application Support/com.campfirecode.scriptquickreply/settings.json`
- Windows：`%APPDATA%\com.campfirecode.scriptquickreply\settings.json`

卸载前或换电脑前请先「导出 JSON 备份」。

## 验收用例

| 操作 | 应得到 |
|---|---|
| 第一次打开 | 左侧分类：开场、产品介绍、价格异议（嫌贵、比价）、催单、售后（物流、退换）、复购、群欢迎语与公告（入群欢迎、群规公告、活动通知、开课提醒）；「全部」24 条，每张卡片标「示例，可删除」；光标在搜索框里 |
| 点左侧「群欢迎语与公告」 | 显示 8 条模板，「入群欢迎：带福利」带置顶标记 |
| 搜索框输入 `rqhy` 回车 | 命中「入群欢迎：…」；弹出填写框，有「成员昵称」「群名」「我的名字」等项。「群名」填「示例群」、「成员昵称」填「小明」后回车，剪贴板内容为「欢迎 小明 加入「示例群」🎉」开头，没填的变量保留 `{…}` 原样 |
| 选「活动通知：标准版」，点复制 | 填写框有「活动名」「活动时间」「活动地点」「活动内容」「报名方式」五项；「活动时间」填「10 月 30 日 19:30」，其余留空回车，剪贴板里「时间：10 月 30 日 19:30」，其余仍是 `{活动名}` 等原样 |
| 直接输入 `cwl`，按回车 | 只剩「查物流」一张卡片；弹出填写框，有「客户称呼」「快递单号」「到货时间」三项。填「王姐」后回车，剪贴板内容以「王姐您好，帮您查了下」开头，提示「已复制「查物流」」 |
| 搜索框输入 `嫌贵` | 先显示标题含「嫌贵」的两条（嫌贵：拆算到每天、嫌贵：给台阶） |
| 点「导入」，选 `samples/我的话术.xlsx` | 提示「从「我的话术.xlsx」导入 6 条话术（1 条重复已跳过）」（文件里有一条重复话术和一个空行）；「全部」变为 30；「社群欢迎语」带置顶标记 |
| 把 `samples/话术备份.json` 拖进窗口 | 新增分类「节日活动」，导入 2 条，「双十一预热」置顶 |
| 点「删除全部示例」→「删除示例」 | 只剩导入的 8 条，顶部提示条消失 |
| 「导出 → 导出 Excel」保存为 `话术库.xlsx` | 表格有「分类、标题、话术内容、置顶」四列，8 行数据；再导入这个文件提示「导入 0 条话术（8 条重复已跳过）」 |
| 关掉程序再打开 | 话术、置顶、分类与关闭前一致 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
